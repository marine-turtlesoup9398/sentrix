# Security Policy

## Security Model and Scope

SENTRIX is a local-first static analysis tool. Target repositories are treated strictly as untrusted data. SENTRIX does not execute build scripts, Makefiles, setup.py files, or target binaries.

---

## Reporting Vulnerabilities

If you discover a potential security vulnerability, please report it privately via GitHub Security Advisories on the repository:

https://github.com/pingsaketchoudhary/sentrix/security/advisories

Please include:
- Description of the vulnerability.
- Steps to reproduce using safe test fixtures.
- Affected versions or crates.

Please do not open public issues for undisclosed security vulnerabilities.
