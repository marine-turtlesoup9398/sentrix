## ✨ Key Features That Make sentrix Special

### 🗺️ Visual Code Explorer
sentrix turns confusing code into a clear, colorful map. You'll see boxes (representing parts of the program) and lines (showing how they connect). This makes it obvious which parts are overloaded or isolated.

### ⚠️ Risk Detection
The tool automatically flags three types of problems:

- **Security risks** — places where hackers could sneak in
- **Complexity risks** — parts so tangled they're likely to break
- **Dependency risks** — pieces that rely too heavily on other pieces

### 📊 Simple Score System
Every program gets a score from 0 to 100. A score above 80 means it's healthy. Below 50 means it needs attention. You'll see this score immediately after analysis.

### 🔎 Deep Search Without the Headache
sentrix uses advanced technology (called "tree-sitter" and "knowledge graphs") to understand code deeply. But you never see that complexity. You just see plain-English results.
